O que é CSS?

O CSS é a linguagem usada para definir o visual e o estilo das páginas Web (cores, fontes, alinhamentos e espaçamentos).

O que é uma Regra CSS?

Uma Regra CSS é a instrução completa que diz ao navegador qual elemento modificar e como modificar. Ela tem 3 partes:

  • Seletor: Quem recebe o estilo (no exemplo acima é o p).
  • Propriedade: O que vai mudar (no exemplo acima é o color).
  • Valor: A nova cor ou tamanho (no exemplo acima é o blue).

Este parágrafo ficará azul graças à regra CSS.
