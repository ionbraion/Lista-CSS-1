Como incluir CSS no html?

1. CSS Inline (Em linha)

O estilo é escrito direto na tag HTML usando o atributo style="". É bom para testes rápidos, mas polui o código.

2. CSS Interno (Embutido no cabeçalho)

As regras ficam dentro da tag <style> na seção <head>. Aplica estilo a toda esta página, mas exige duplicar código se houver outras páginas.

3. CSS Externo (Arquivo separado)

As regras ficam em um arquivo .css separado e são conectadas via tag <link>. É o padrão do mercado pois permite reaproveitar o estilo em várias páginas.
